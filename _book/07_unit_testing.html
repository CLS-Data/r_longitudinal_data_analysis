7  Unit Testing

In the last chapter, we created cleaned versions of the MCS and NCDS to use to assess the association between childhood/adolescent cognitive ability and body mass index (BMI). However, the code did not include any checks of the the data. As it is possible that mistakes are included in our code, it is best practice to include unit tests to determine whether the data conforms to expectations. In this chapter, we will use the (non-tidyverse) package pointblank to create a series of tests for our data. This package contains an array of helper functions that produce errors, halting code, if data do not follow user-specified rules. For instance, that variables such as BMI which conceptually should not be negative, do in fact not contain any negative values.

We will also use this opportunity to perform some less formal checks to determine whether the data conforms to expectations - specifically, whether the distributions of variables are as anticipation and whether values are biologically plausible. In practice, the results of these formal and informal tests should feed back into our code development, to ensure the errors do not arise in the first place. But for the purposes of this chapter, we will run the tests on the cleaned datasets as they are, editing and resaving them, to demonstrate how to use pointblank and perform other data checks.

The packages we will use are:

library(tidyverse)
library(pointblank)
library(skimr)
library(dlookr)
library(summarytools)

df_ncds <- readRDS("data/ncds_clean.Rds")
df_mcs <- readRDS("data/mcs_clean.Rds")

Let’s start with the less formal checks and move on to the more formal checks.

One important data check is to determine whether missingness levels increase for later measurements, as should be expected given attrition in longitudinal studies. We can see that this is the case for cohort member BMI and weight. It is not the case for height, but this is explainable as we used earlier adult measurements to deterministically impute later height values. We also see that the covariates collected in cohort members’ childhood (e.g., parental BMI and education) generally have lower missingness than the adult anthropometric measurement, though the missingness for year’s of education is relatively high, which we could investigate further.

The data cleaning of anthropometric variables in Chapter 6 was relatively limited and focused on recoding negative values as R’s NA. We can see this decision could be improved as there are a number of biologically implausible values - e.g., the shortest height at 42y was 0.59m and the lowest weight was 0kg, which must be mistakes. So let’s use this opportunity to restrict height and BMI to more plausible ranges (1.4 - 2.1m for height, 13 - 50 kg/m2 for BMI) and to say that weight should be at least strictly positive. These rules are relatively simple and could be improved further, for instance by using heuristics for detecting outliers (+/- 3 SD from the mean) or looking within person at how much temporal stability there is in their data and selecting the most plausible values where they exist. Note, as the BMI and obesity variables are a function of height and weight, we set both to missing if height or weight have been set to missing, too. We use the dplyr::if_else() to recode obese as ifelse() can strip attributes of a variable, obese would no longer be a factor variable.

ncds_updated <- df_ncds %>%
  mutate(
    height = case_when(fup >= 20 & between(height, 1.4, 2.1) ~  height,
                       fup < 20 ~ height),
    weight = ifelse(weight > 0, weight, NA),
    bmi = case_when(is.na(height) ~ NA,
                    is.na(weight) ~ NA,
                    between(bmi, 13, 50) ~  bmi),
    obese = if_else(!is.na(bmi), obese, NA)
  )

7.2 Unit Testing with pointblank

We can now move on to more format unit testing using functionality within the pointblank package. This package contains many specific unit tests functions which cannot be summarised fully here (see the package website for more details). If a unit test fails, the functions error, halting code. Here we pick out two salient pointblank functions:

ncds_updated %>%
  col_vals_gt(c(height, weight, bmi), 0, na_pass = TRUE) %>%
  col_vals_expr(~ bmi == weight / height ^ 2, na_pass = TRUE)
